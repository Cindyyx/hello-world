Faces and namesPastilles et noms

How TallyUp tells apart people who start with the same letter.Comment TallyUp distingue les personnes qui commencent par la même lettre.

Just enough lettersJuste assez de lettres

Everyone shows their first initial, unless someone else in the trip starts with the same letter. Then their faces grow only as much as needed, trying these steps in order:

StepExample
First and last initialSarah Lee + Sam Kim → SL / SK
More of the first nameSarah + Sam → Sar / Sam
Every word's initialMary Ann Lee + Mark Lee → MAL / ML
First initial + start of the last nameSam Lee + Sam Lo → SLe / SLo
First two letters + last letterSara + Sarah → Saa / Sah
First two letters + where the spellings partHannah + Hanah → Han / Haa

Only names that are otherwise the same fall back to an emoji or a number.

Chaque personne affiche sa première initiale, sauf si quelqu'un d'autre dans le voyage commence par la même lettre. Leurs pastilles s'allongent alors juste autant que nécessaire, en essayant ces étapes dans l'ordre :

ÉtapeExemple
Initiale du prénom et du nomSarah Lee + Sam Kim → SL / SK
Plus de lettres du prénomSarah + Sam → Sar / Sam
L'initiale de chaque motMary Ann Lee + Mark Lee → MAL / ML
Initiale du prénom + début du nomSam Lee + Sam Lo → SLe / SLo
Deux premières lettres + dernière lettreSara + Sarah → Saa / Sah
Deux premières lettres + là où l'orthographe diffèreHannah + Hanah → Han / Haa

Seuls des noms autrement identiques passent à un emoji ou à un numéro.

Where faces showOù s'affichent les pastilles

On trip cards, in Trip settings, in Who's coming, in the Sheet view and on By item rows. Emoji stay whole, so 👨‍👩‍👧 or 🇨🇦 never break into pieces.

Sur les cartes de voyage, dans les paramètres du voyage, dans Qui vient, dans la vue Feuille et sur les lignes Par article. Les emojis restent entiers : 👨‍👩‍👧 ou 🇨🇦 ne sont jamais coupés.

A hint when adding someoneUne suggestion quand on ajoute quelqu'un

Typing a name that starts like someone already in the trip shows both faces and suggests adding a last name or an emoji. It's only a hint: the name can still be added as typed.

Taper un nom qui commence comme celui d'une personne déjà dans le voyage affiche les deux pastilles et suggère d'ajouter un nom de famille ou un emoji. Ce n'est qu'une suggestion : le nom peut quand même être ajouté tel quel.
