Offline and sync

Keep adding expenses with no signal. Everything syncs when you're back.

Working offline

Expenses are stored on your phone and sync when you're back online. A small sync pill always shows whether your changes reached the cloud. Search works offline too.

Two people, same expense

Each edit is checked against what the device last saw.

  • Changes to different fields merge.
  • The amount, rate and split are saved as one unit, so shares always add up.
  • If two people changed the same thing, the later one isn't overwritten silently: they get a Review banner with Keep current or Use mine.

Nothing lost silently

A change the server refuses, for example after your access changed while you were offline, is listed in a banner you can copy. Every expense has an edit history, timed by the server.

When a new version is out, you see "A new version is ready" and reload when you choose. Unsynced changes stay queued on the device.
